# Repository maintenance history

Scientific findings, their original scope and dated publication history remain
in the modular `changelog.tex` document. This file records repository structure,
navigation and maintenance changes that make no new scientific claim.

## 2026-10-18 — Paper navigation in the shared Atlas

The maintained local Atlas now imports the registry's exact document/section
identities, complete section text and typed evidence references. Dedicated
paper search, outline, section, evidence and coverage tools expose source-bound
AI descriptions without changing the ledger or curated research verdicts.
The common skill and agent entry describe bounded retrieval, original-source
checks, public/private scope and separate source/context/review coverage.

The registry now resolves nested includes from the original document compile
directory through the shared TeX reader. This corrects five false incomplete
document views and restores 73 section memberships; the 6,693 physical public
section identities and authored source bytes are unchanged. A regression keeps
missing or undeclared dependencies visible instead of silently accepting them.

## 2026-10-18 — Retire the shadow mirror and clarify semantic coverage

At the user's request, the automated `tfpt5-shadow` mirror is retired. Its
GitHub workflow was disabled and the workflow source removed. The remote
repository is archived/read-only with its history retained; no shadow-sync token
renewal is needed. `scripts/export-shadow.sh` remains an optional legacy
utility with its source-coherence safeguards; it has no active mirror workflow.

`SEMANTIC_NAVIGATION.md` documents the distinction between complete structural
registry navigation and incomplete reviewed section-level semantics, with
dated Atlas observations and a precise next-session retrieval route. Registry
entries, lexical topics, AI annotations and vector availability do not upgrade
scientific status. All scientific sources and historical statements are unchanged.

## 2026-10-18 — Modular LaTeX and central source registry

The long authored LaTeX sources were moved into document-owned preambles and
bounded source modules. Existing entry points, compile directories and published
PDF names remain stable. The migration inventory records all original standalone
documents, immutable snapshots and shorter sources; original module bytes and
ordered include expansions were verified before integration. No mathematical
statement, input premise or claim status was upgraded.

The central generated registry documents source ownership, sections, topics,
registered Python checks, ledger claims, explicit Lean/Wolfram references and
unresolved links. Concise agent entry data and bounded queries accompany the
complete machine-readable index. Local unpublished sources have a separate,
ignored registry supplement. The registry is navigation, not proof validation.

The source readers, existing document guards, manifests and filtered Overleaf
export were adapted to the actual modular include paths. A compact introduction
and a separate verification reference volume complement the original full PDFs.
The website document library links these reading paths and registry downloads.
`README.md` and `AGENTS.md` now explain ownership, editing, regeneration,
research scope and validation from a single maintained entry route.
