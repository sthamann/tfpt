# Frozen nonlinear digit prediction protocol — 2026-09-08

Written before generating new digits or measuring this gate's outcomes. Motivation: previous fixed linear digit predictors did not generalize. A joint categorical relationship can exist despite uninformative single-digit marginals. This experiment tests one bounded nonlinear search family, with its selection cost included in calibration.

Data: extend pi, e and sqrt(2) to 13,200,032 decimal digits, compare each old 10,400,000-digit prefix to its verified predecessor, repeat pi at increased MPFR precision. Training prime positions 11,000,001..11,200,000; model-selection positions 12,000,001..12,200,000; final-test positions 13,000,001..13,200,000. All features use just positions p..p+7, indexed from 1 after the decimal point. All actual reads are beyond the previously examined data, and the three ranges are disjoint. The repeated pi computation is a precision-stability check, not an independent suffix algorithm.

Target: y=log((next_prime(p)-p)/log(p)). Baseline: the preceding prediction-gate's fixed arithmetic Ridge model (penalty 100), trained on the training range only, using log(p), four previous normalized log gaps, and categorical residues modulo 30,7,11,13,17,19. Pin source SHA256 e4882ff9d0ed3c859c06a4db0c973c7d3f529a3a2fcdd800ce182f9c944f3e3d. No next-gap label is used as a baseline feature.

Learn tables of TRAINING residuals y-baseline. For category c use sum(residuals in c)/(count(c)+50), including empty categories as zero; smoothing 50 is fixed. No refitting after model selection.

Single-digit control search: eight categorical tables, one for each offset 0..7, plus no correction. Nonlinear search: all 28 unordered pairs of distinct offsets among 0..7 (100 categories), and six contiguous triples starting at offsets 0..5 (1000 categories), plus no correction. For each search select the model with lowest MSE in the separate model-selection range, using the fixed order no-correction, lexicographic pairs, then triples (or ascending single offsets) for ties. Select without accessing final-test labels. Freeze that model for the final test. No threshold, smoothing, offset, or predictor tuning after outcomes.

Two co-primary statistics: relative final-test MSE reduction of selected nonlinear model (1) versus arithmetic baseline and (2) versus selected single-digit control. Calibrate both on 999 independent full uniform decimal streams, seed 202609085501, rerunning training AND all model selection for each stream. One-sided inclusive add-one p values, Holm over the two statistics. A candidate requires both adjusted p<.05, >=1% MSE reduction versus arithmetic baseline, positive incremental reduction versus the single-digit control, and positive reductions for BOTH comparisons in EACH final-test half (p<=13,100,000 and p>13,100,000). No observation in the final test may choose the winning model. Report selected offsets, training/selection/test scores, all observed selection scores, and null results. e and sqrt(2) are descriptive controls.

Positive control: create a separate random stream with seed 202609085502. Let b indicate y greater than the TRAINING target median. At every sampled prime p set d[p+1]=(2+5*b-d[p]) mod 10. Thus the pair's sum mod 10 encodes the gap class, while each individual digit is marginally uniform under the random construction. Prime positions here differ by at least two, so modified pairs do not conflict. Training, selection and final-test labels are deliberately planted for this sensitivity check only. It must pass both co-primary criteria; no claim about power for weak/general nonlinear signals follows.

Audits: direct context slicing and categorical accumulation against independent loops; label and preceding-gap checks with SymPy; fixed selector invariance to final-test label changes; independent recalculation of saved prediction metrics, selected-model optimality on selection data, and Monte Carlo ranks; reproduction of the first full null stream. Code/data/protocol hashes, timings and all failures recorded. No RH, normality, global independence or factorization-speed claim. This is an internally frozen protocol, not an external preregistration.
