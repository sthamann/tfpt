Keine E8-Erweiterung der Bilinearströme der acht gefalteten Kanäle erfüllt mit
dem ursprünglichen Fold-Zeitgesetz zugleich (a) die Ward-Markierung `q/2` ∈ E8 und
(b) ein eindeutiges Vakuum:
* Ward-Markierung erzwingt die s-Chiralität;
* s hat den Nullzustand p* = (½⁴, −½⁴), in der Branche 0 ≤ α ≤ 1 für jede
  Randphase. Solange das Vakuum Grundzustand bleibt, hebt keine U(1)-Verdrillung
  die Entartung auf; die Invariantenprojektion auf U(1), Clock und Deck entfernt
  p* nicht;
* die c-Chiralität hat ein eindeutiges Vakuum, verliert aber die Ward-Markierung.

Dazu bestätigt: Eine Randphase h wird auf dem Doppel zu h²; die Deck-Sektoren der
Basis tragen h und −h. Details: `PROOF.md`.
