1. Native exact constants
-------------------------

reflections have the same squared-distance histogram for x=alpha/2:

  |x(r alpha)-x(alpha)|^2 : 0^15, 1^32, 2^12, 4^1.

Thus exactly 15 reflections fix each root and

  (1/60) sum_r |x(r alpha)-x(alpha)|^2 = 1                 (1)

for every alpha.  The corresponding incoming column sum is also one.  These
are the two exact constants needed below; they are not fitted large-m values.

2. Trial state and total locking gradient
-----------------------------------------

registers in psi_alpha=alpha/2.  Every H_E,e annihilates this state.  In L_e,
only the 15 source reflections fixing alpha survive the source expectation,

  <L_e> = 1-15/60 = 3/4,
  E_0 <= 3 kappa m/4.                                      (2)

All terms are positive.  Since

  1-x_e dot x_{e+1} = |x_{e+1}-x_e|^2/2,

3. Endpoint assertion: verified and sharpened

6. Sharper q-specific finite-model criterion
---------------------------------------------

The natural normalized real open-chain profiles are

  q_n = pi n/m,  n=1,...,m-1,
  w_e^(n) = sqrt(2/m) cos[q_n(e-1/2)].                    (16)

They have zero sum and unit norm.  Their discrete antiderivative obeys the
exact identity

  sum_{k=1}^{m-1} W_k^2 = 1/[4 sin^2(q_n/2)].             (17)

Hence the total static source-coordinate response and its first moment obey

  S_0(n) := sum_a int S_aa(n,omega)d omega
            <= 3 kappa m/[8 mu sin^2(q_n/2)],             (18)

  S_1(n) := sum_a int omega S_aa(n,omega)d omega
            <= kappa/2.                                   (19)

This yields a direct finite-model acceptance gate.  A claimed pole or
frequency window of total residue Z at q_n must satisfy

  Z <= 3 kappa m/[8 mu sin^2(q_n/2)].                     (20)

If that window lies above omega_min>0, (19) additionally requires

  Z <= kappa/(2 omega_min).                               (21)

For a sequence with q_n bounded away from zero and mu>=3 kappa m^2,

  S_0(n) <= 1/[8m sin^2(q_n/2)] -> 0.                     (22)

Therefore no fixed-nonzero-q SOURCE-COORDINATE pole can retain nonzero
residue in that joint limit, whether the pole is slow or fast.  A spectrally
dark excitation is not excluded.

The order of limits matters.  For fixed mode number n, q_n=pi n/m tends to
zero, and the same scaling gives only

  S_0(n) <= m/(2 pi^2 n^2) [1+o(1)].                     (23)

This does not suppress the collective long-wave sector.  Suppressing that
bound would require mu/(kappa m^3)->infinity.  Thus (22) must not be stated as
an all-q thermodynamic theorem.
