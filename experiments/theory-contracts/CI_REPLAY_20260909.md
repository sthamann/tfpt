# Research replay portability follow-up — 9 September 2026

The published run [34320429999](https://github.com/sthamann/tfpt/actions/runs/34320429999)
failed on four of the 61 modules, on Python 3.11 and 3.12, in both ordinary
and optimized modes. The original local 971-test-per-mode record remains
a historical local result, not evidence that this GitHub run passed.

## Reproductions before changes

1. The stored source provenance in `compiler-involution-types` (both test
   modules) and `clock-bilinear-response` contains the original absolute
   repository path. A source-byte-identical relocated archive reproduced
   the failure; the expanded comparison differed only in that path.
2. `carrier-module-conjugation` compares floating diagnostics bit for bit.
   On the same actual source at N=8, the SVD norm returns
   `2.0000000000000004`, while the Gram-eigenvalue norm returns `2.0`.
   Both pass the existing source's strict 1e-12 bound. Replaying the stored
   certificate with the latter legitimate norm computation reproduced
   its equality failure. This establishes a portability defect; the first
   CI run did not publish individual tracebacks, so the precise failing
   Linux floating value was not retrieved.
3. The consolidation runner wrote full failure tracebacks only to a local
   JSON file that CI did not retain. A failing-child regression reproduced
   the absence of the error from the visible log.

## Narrow fixes, without changing the scientific sources

- `record_portability.py` canonicalizes exactly one provenance source path,
  accepting only the original root or the current root. The recorded hash
  and actual file bytes must both match the frozen source hash. Other
  paths, fields, formula values, prefixes and scope flags are not normalized.
- The two carrier floating diagnostics are checked against their exact
  source targets using the SAME strict 1e-12 limits already enforced by
  the pinned checker. Only after that check are they canonicalized for
  replay comparison. NaN, infinities, negative norms and changed exact
  fields are rejected. No numerical tolerance was enlarged.
- Four unpinned test files use those comparison functions. No checker,
  source pin, historical JSON certificate or scientific formula changed.
- Failed child transcripts are printed. CI now has an always-run artifact
  upload for the complete JSON and runs the new guard tests in both modes.

  mode** (9 carrier, 17 clock response, 9 involution, 3 clock selection).
- The alternate Gram-norm reproduction now passes without changing its

  These changes have not been committed or pushed; the published manifest
