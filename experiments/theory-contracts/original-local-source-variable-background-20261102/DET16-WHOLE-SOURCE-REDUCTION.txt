2. COMPLETE THERMAL MIRROR SOURCE, INCLUDING Z[0]

For beta>=0 put a=exp(-2 beta), b=1-a. Since P^2=P,

 E_beta=exp(-beta H_m)=a I+b P,
 Z_m=Tr E_beta=d a+b=1+(d-1)exp(-2 beta),
 rho_m=E_beta/Z_m.                                      (1)

For EVERY mirror operator A,

 omega_beta(A)=[a Tr A+b<phi|A|phi>]/Z_m.                (2)

This is the entire finite source state, not a covariance fit. The scalar
identity part of H_m is retained. Removing it from a commutator is valid;
removing it from this unnormalized source would change Z_m and energy.
The same original reference source, if present, contributes its actual
corresponding factor; no equality of reference factors is assumed.

The native original CAR trace gives for all i,j

 <c_i^*c_j>=delta_ij/2,    <c_i c_j>=0,

 <Omega_16>=b exp(i vartheta)/(2Z_m).                    (3)

Here Omega_16=|0><F| has the actual original determinant sign. For beta>0
the density-pair excess is positive: the source is not quasifree even

3. ALL GEOMETRICALLY ORDERED MIRROR WORDS

Let A_0,...,A_(k-1) be actual mirror CAR letters in their written order,
and let nonnegative heat intervals t_0,...,t_k sum to beta. The complete
unnormalized Euclidean coefficient is

 W=Tr[E_t0 A_0 E_t1 A_1 ... A_(k-1) E_tk].              (4)

Each E_t is exactly a_t I+b_t P. Expanding this identity is a proof for
every finite word, but its literal2^(k+1) expansion is unnecessary.
For each term with projector cuts use

 Tr(P B_1 P B_2 ... P B_r)=product_j <phi|B_j|phi>.      (5)

The blocks B_j keep the actual order and original fermion signs. The
P-free term is exp(-2 beta) times the ordinary CAR Fock trace.

4. MATRIX-FREE CYCLIC RENEWAL, POLYNOMIAL IN WORD LENGTH

By cyclicity combine the last and first heat intervals. Write the resulting
k cyclic intervals as delta_i, each immediately before A_i. For i<j<=i+k
define, with periodic indices,

 e(i,j)=b_(delta_i) exp[-2 sum_(r=i+1)^(j-1)delta_r]
                  *<phi|A_i A_(i+1)...A_(j-1)|phi>.     (6)

For any nonempty set of selected P cuts, multiplying the consecutive
cyclic edge weights gives exactly that term of (4): every selected cut
contributes its b, every unselected interval its a, every block its
matrix element. No reordering of CAR letters is made.

There is a unique smallest cut i in {0,...,k-1}. Fix it, put D_i=1, and
compute for j=i+1,...,k-1

 D_j=sum_(h=i)^(j-1) D_h e(h,j).

Its complete closing contribution is sum_(h=i)^(k-1)D_h e(h,i+k).
Sum over i and add the P-free term. Every nonempty subset of cuts is
counted exactly once by its unique ordered path and smallest cut.
The empty word is Z_m itself. Divide by Z_m only for normalized answers.

For a CAR-letter block, <phi|B|phi> requires only applying that word to
the two bit states0 andF. For its full Fock trace, work right to left:
the first action on each used mode forces its initial occupation. Check
the resulting word on that initial bit choice. If it is zero or changes
the initial state, the trace is zero. Otherwise its sign is independent
of unused spectator bits: every acted mode flips an even number of times,
so the total Jordan-Wigner exponent of any spectator bit is even.
Thus Tr B=sign*2^(16-number_of_used_modes).

There are O(k^2) possible edges, each calculated in O(k), and the dynamic
path sums cost O(k^3). Stored edges cost O(k^2). These are exact arithmetic
operation counts at the fixed original16-mode factor. Floating evaluation
retains ordinary numerical precision limits; no uniform relative-error
claim for arbitrarily tiny answers or arbitrary bit-complexity is made.
The evaluator uses no Hilbert-space matrix for this renewal calculation.
It does not claim efficient input access to arbitrary unspecified operators.
