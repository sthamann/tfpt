## 1. Wo deine Einfachheitsintuition trägt

Die v1.6.1-Arbeit zeigt bereits: Ein zusätzliches Fermion ermöglicht neue innere Übergänge, ohne eine neue Wechselwirkung einzuführen.

Die nächste Vereinfachung lautet aus meiner Sicht:

> **Wir müssen eine Anregung zusammen mit dem Hintergrund betrachten, den sie verändert.**

Ein zusammengesetztes Objekt über einem leeren Zustand kann genau dasselbe Ergebnis liefern wie eine Entfernung aus einem besetzten Zustand. Hier lässt sich das einschließlich aller Vorzeichen und Normierungen beweisen.

Das ist zunächst eine Aussage über konkrete Zustände des vorhandenen Modells. Sie benötigt keine zusätzliche Kraft.

## 2. Der exakte Anschluss: Der Dreierkomposit ist ein Loch

Die neue Notiz enthält die 64 zusammengesetzten Felder \(\chi_r^\dagger\). Sie erzeugen aus dem leeren Zustand jeweils einen Vermittler plus ein Fermion und erhöhen die erhaltene Zahl \(N\) um drei.

Ich habe daraus den normierten Zustand

\[
|Q_4\rangle=
\frac1{\sqrt{128}}
\sum_{r=1}^{64}f_r^\dagger\chi_r^\dagger|0\rangle
\]

gebildet.

**„Vierer“ bedeutet hier \(N=4\): ein Boson und zwei Fermionen.** Es sind nicht vier freie Fermionen und auch nicht der frühere Vierträgerzustand \(\Omega\).

Für sämtliche 64 Moden ergibt sich exakt:

\[
\boxed{\sqrt{32}\,f_r|Q_4\rangle=\chi_r^\dagger|0\rangle.}
\]

Anschaulich:

```mermaid
flowchart LR
    A["Leerer Zustand · N = 0"] -->|"Komposit erzeugen · +3"| C["Derselbe Dreierzustand · N = 3"]
    B["Viererhintergrund · N = 4"] -->|"Fermion entfernen · −1"| C
```

**Damit ist die Ladungsdifferenz auf der Ebene dieser Zustände aufgelöst.** Sie wurde weder ignoriert noch nur modulo vier umbenannt.

Die wichtige Unterscheidung bleibt: Das beweist keine globale Operatorgleichung \(\chi_r^\dagger=f_r\). Die beiden Operationen wirken auf unterschiedliche Hintergründe. Auch die relativistische Antiteilcheninterpretation und der vollständige Anschluss an die tatsächliche TFPT-Clock bleiben eigene Aufgaben.

## 3. Auch seine Dynamik bleibt einfach

Der passende Viererzustand koppelt unter dem **unveränderten** Hamiltonoperator nur an einen bestimmten Zweibosonzustand. Alle Beiträge zu vier freien Fermionen heben sich auf.

Die gesamte Dynamik dieses invarianten Teilraums lautet:

\[
\boxed{
H_4=
\begin{pmatrix}
\Delta&4g\\
4g&2\Delta
\end{pmatrix}.
}
\]

Es handelt sich um eine exakte Reduktion, ohne abgeschnittene Restkopplungen.

Auf dem unteren Eigenzustand dieses Blocks führt die Entfernung eines Fermions wieder genau in den geschützten Dreierkomposit. Die dafür benötigte Energie ist

\[
\boxed{
\varepsilon_h=
\frac{\sqrt{\Delta^2+64g^2}-\Delta}{2}
=
\frac{16g^2}{\Delta}
+O(g^4/\Delta^3).
}
\]

Bei \(g/\Delta=1/20\) beträgt sie etwa

\[
\varepsilon_h=0{,}03851648\,\Delta.
\]

**Dieselbe Dreieranregung hat über dem leeren Zustand Energie \(\Delta\), als Loch über diesem Viererhintergrund jedoch einen viel kleineren Energieabstand.** Auch ihre Zweizeitantwort lässt sich vollständig angeben.

Das ist noch keine räumliche Teilchenmasse: Dafür fehlt eine hergeleitete Ausbreitung mit Impulsabhängigkeit.

### Die entscheidende Gegenprüfung

Dieser Viererhintergrund ist bei der dokumentierten schwachen Kopplung **kein Grundzustand des vollständigen N=4-Sektors**. Ich habe einen anderen N=4-Zustand konstruiert, der bereits einen negativen Variationswert liefert, während die Energie unseres Viererhintergrunds positiv ist.

Damit steht der Befund sauber:

- **Der lokale Lochanschluss funktioniert exakt.**
- **Warum die Natur einen passenden Hintergrund auswählt, ist dadurch noch nicht erklärt.**

Die früheren Quellen berichten bereits kleine N=4-Blöcke. Ich beanspruche deshalb keine erstmalige Entdeckung dieses Sektors; der hier ausgearbeitete Schwerpunkt ist sein expliziter Anschluss an die 64 Kompositfelder.

## 4. Zwei weitere Vereinfachungen

### Die Feldnorm hängt auf einem symmetrischen Hintergrund nur von zwei Zahlen ab

Die Kompositfelder erfüllen global keine freien Fermionregeln. Ihre Abweichung lässt sich aber exakt auf Boson- und Fermiondichten zurückführen.

Auf einem unter Spin(10) und SU(4) invarianten Zustand folgt:

\[
\boxed{
\langle\{\chi_r,\chi_s^\dagger\}\rangle
=
\delta_{rs}
\left(
1+\frac{\langle N_b\rangle}{60}
-\frac{\langle N_f\rangle}{64}
\right).
}
\]

Im Sektor \(N=64\) wird daraus:

\[
\boxed{
Z_\chi=\frac{23}{480}\langle N_b\rangle.
}
\]

Das macht den nächsten Schritt wesentlich konkreter: Für den berichteten nativen Singulettgrundzustand hängt die gesamte gleichzeitige Kompositnorm an **einer einzigen mittleren Bosonbesetzung**.

Diese Norm ist eine Spektralsummenregel. Sie beweist noch keinen einzelnen Teilchenpol oder einen freien Feldgrenzwert.

### 45.504 Zustände benötigen unter den beiden Kontrollen nur 14 Algebraelemente

Für die dokumentierten Kontrollen „Konversion“ und „Bosonbesetzung“ habe ich die vollständige N=3-Kontrollalgebra bestimmt:

\[
\mathcal A_3
\cong
\mathbb C\oplus\mathbb C
\oplus
\bigoplus_{\lambda=7,10,12}
\left(M_2(\mathbb C)\otimes I_{m_\lambda}\right),
\qquad
\dim\mathcal A_3=14.
\]

Die große Zustandszahl besteht hier aus drei Arten von Zweizustandsdynamik und zwei dunklen Bereichen mit hohen Vielfachheiten.

Das vereinfacht weitere Rechnungen mit denselben Kontrollen erheblich. Aus den drei Schwingungstypen folgen allerdings keine drei Raumdimensionen.
