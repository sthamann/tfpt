Question
--------
In the original v1 E8 coordinates, does the actual compiler clock C preserve
the existing D8 current subsystem, or does clock covariance force the
half-spinor/Ramond currents?  This is a fixed-dictionary representation test.
It is not a construction of a detector, a Hamiltonian, or a raw-source field.

  112 integer roots  +/-e_i +/-e_j                       (D8 roots),

  240 roots total                                        (selected E8).

rank-eight Cartan.  The root count is therefore 112, not 120.  The pinned .21
source24 set is a 24-element subset of the selected even-parity half-spinor

  D8 roots         112  112  112  112  112  112  112  112  112

The first n for which U_n is the complete selected E8 root system is n=8.
This is the smallest clock-power completion for this fixed D8 seed and actual

There is also a shorter algebraic closure statement.  Start with all D8 roots
and one displayed spinor root together with its negative.  Repeatedly add two
active roots whenever their sum is an E8 root.  The support sizes are

  114 -> 170 -> 240.

For Chevalley root spaces, a pair whose sum is a root has a nonzero bracket.
Consequently the D8 current algebra plus one spinor current and its adjoint
generates all selected E8 root spaces.  This statement concerns Lie-algebra
support.  It does not select cocycle phases or construct a local field
implementation.

Fixed-dictionary obstruction
----------------------------
The actual C has characteristic polynomial

  Phi_30(x) = x^8 + x^7 - x^5 - x^4 - x^3 + x + 1.

An automorphism of the fixed D8 root system acts on its Cartan reflection
coordinates by a signed permutation.  A signed cycle of length l contributes
x^l-1 or x^l+1.  Exhaustive exact enumeration of all signed cycle types of
total dimension eight finds no characteristic polynomial Phi_30.  The actual
J is itself a signed-permutation matrix and passes this control.

Therefore C is not an automorphism of the fixed source D8 root system and
cannot be the same Gaussian linear action on the fixed 16-Majorana carrier
while also realizing the specified action on its chosen Cartan/root
dictionary.  This says nothing about a changed Cartan, an abstract conjugate
compact D8 subgroup, or a nonlinear action on the E8 simple-current
extension.

The 60-ray quotient does not retain C
-------------------------------------
The original 60 rays are the 60 four-element J-orbits of the 240 full roots.
For C to descend to this quotient, all four representatives of each source
J-orbit would have to land in one common target J-orbit.  Exact enumeration
gives the target-orbit multiplicity histogram

  number of distinct target J-orbits = 2 : 60 source orbits.

Thus C fails the fixed-J, same-label descent criterion on every one of the 60 rays.  For the
explicit D8 witness above, its four J-related representatives map under C to
a spinor pair and a D8 pair belonging to two different target J-orbits.  A
process intended to retain both actual clocks cannot use only the 60-ray
label with a frozen J frame as its complete state.

There is a canonical moving-frame quotient alternative.  Put J'=C J C^-1.
If beta=J^k alpha, then C beta=(J')^k C alpha, so

  ([alpha]_J, J) -> ([C alpha]_(J'), J')

is well-defined.  A covariant process may therefore transport this relational
frame rather than store a literal 240-root register; retaining the full-root
representative or equivalent phase/current-lift data are other options.  The
checker does not derive a physical or dynamical rule that selects and carries
J'.  This is a fixed-frame quotient obstruction, not a derivation of a
particular record carrier.

Chirality control
-----------------
C preserves the selected even-parity E8 extension.  Applied to the 128 roots
of the opposite odd half-spinor chirality, C sends all 128 to quarter-entry
vectors outside both standard E8 root systems.  J preserves both chirality
extensions.  Thus the actual C and the pinned .21 source24 are compatible in
this coordinate dictionary.  This is only a compatibility rejection of the
opposite chirality: C was itself constructed from the already selected E8
simple-root system containing an even half-spinor root, so reversing this
comparison would be circular and cannot independently derive chirality.

What is not gained

An E8 current symmetry may act nonlinearly on the free-fermion extension; the
fixed-carrier Gaussian obstruction does not exclude that possibility.
