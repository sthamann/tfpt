* `X⊗1` verlässt Λ², aber `P₋(X⊗I)P₋ = ½dΓ(X)` existiert. Ein bilokaler Zeittransport ist
  eine Möglichkeit für C, keine Notwendigkeit (korrigiert). Familienblinder Transport

  gilt `{±x, ±¼, ±¼}` mit `x = 3/16` oder `1/16` (je nach Kleidung), auf den Marken
  das Muster 1+1+2.

  Ein Zeitlauf von h folgt nicht.
