# Familien-Zeitgenerator aus dem ursprünglichen Fold-Zeitgesetz (14. Oktober 2026)

Status: **PARTIAL**, keine Promotion. `python3 checker.py`: 86 exakte Prüfungen.

* Auf identischen CAR-Moden gibt es keine Ein-Bein-Clock. Eine Relativwirkung für
  `Y_C = CᵀA − AC` muss der Transport zwischen zwei Zeitpunkten im bilokalen
  nativen Austausch sein. Familienblinde Zeit ergibt Y = 0.
* Das ursprüngliche Fold-Zeitgesetz `δ_k = (k+α)/8 − ½` hat für jede ehrliche Kleidung
  einen nichtskalaren Familienanteil δ_F. Auf den sechs (10,6)-Familiengewichten
  gilt `{±x, ±¼, ±¼}` mit `x = 3/16` oder `1/16` (je nach Kleidung), auf den Marken
  das Muster 1+1+2.
* Damit liegt ein quellseitiger relativer Familientransport `exp(i(τ−σ)δ_F)` vor.
  Offen bleibt die Identifikation des Nahtfermions mit den nativen W-Moden und der
  Lorentz-Austausch-Intertwiner. Details: `PROOF.md`.
