2. The actual coordinate bridge

Let C,J be the eight-dimensional matrices in the pinned original integral
triality certificate. The standard roots have norm squared2. Their set is
the112 vectors +/-e_i +/-e_j together with the128 even half-sign vectors.
J acts on each adjacent coordinate pair as [[0,-1],[1,0]].

The source_channel.py implementation instead uses Gaussian integer roots
of norm squared4, grouped into sixty quarter-phase orbits. Define

  A=I+J.                    A^T A=2I,       AJ=JA.

An exact all-root comparison proves

  A {standard240 roots} = {actual240 Gaussian source roots}.

Thus A is a specified similarity and coordinate dictionary, not an
orthogonal automorphism of one fixed-normalization lattice. Its uniqueness
is not asserted. The actual original clock in Gaussian coordinates is

  C_G=A C A^-1.

It is orthogonal and permutes all240 native labels. Consequently the
following test compares the actual clocks and actual source implementation,
rather than two abstract objects with equal dimension.

3. A collision that forbids the fixed-ray clock map

For a nonzero real root alpha define

  Pi_alpha^J = [alpha alpha^T+(Jalpha)(Jalpha)^T]/||alpha||^2.

This is the real rank-two projector representing the complex rank-one
projector Q_alpha on C4. In particular Pi_alpha^J=Pi_(Jalpha)^J.

Take the native Gaussian roots

  alpha  = (0,2,0,0,0,0,0,0),
  Jalpha = (-2,0,0,0,0,0,0,0).

Their original normalized complex overlap has squared magnitude1. The
actual clock sends them to

  C_G alpha  = (0,-1,1,0,0,-1,-1,0),
  C_G Jalpha = (1,1,1,1,0,0,0,0).

In the SAME fixed J frame the squared complex overlap is now1/4, and

  ||Pi_(C_G alpha)^J-Pi_(C_G Jalpha)^J||_F^2=3.

Equal input projectors would have to map to unequal output projectors.
Therefore no well-defined map on this fixed ray quotient implements the
specified C root relabelling. In particular no fixed C4 unitary or
antiunitary projector map does so. Multiplying root vectors by cocycle or
lift phases cannot repair equality of the input projectors.

This is a statement about that dictionary. It does not assert that every
possible nonlocal or source-dependent implementation of C is impossible,
nor that C has been required to commute with the previously chosen H.

4. Choosing a different integral fixed frame cannot make C complex-linear

There is also a result independent of the selected J. Suppose J_* is any
endomorphism of the E8 root lattice satisfying

  J_*^2=-I,                    C J_*=J_* C.

Choose the explicit integral root basis B recorded in checker.py. Its
columns are roots and all240 roots have integral B coordinates, so its
integer span is exactly the root lattice. C_B=B^-1 C B is integral. Reduce
both C_B and J_* modulo31. The characteristic polynomial of C_B is

  Phi30(x)=x^8+x^7-x^5-x^4-x^3+x+1.

Over F31 it has the eight DISTINCT roots

  3,11,12,13,17,21,22,24.

Therefore C_B has eight one-dimensional eigenspaces over F31, and every
commuting matrix preserves each of them. J_* acts on each line by a scalar
j. But J_*^2=-I would require j^2=-1 in F31. Direct enumeration (equivalently
31=3 mod4) shows this has no solution. Contradiction.

Thus no such lattice endomorphism exists. In particular no root-preserving
orthogonal complex structure can make the original C complex-linear on a
single fixed Gaussian lattice presentation.

The anti-linear alternative would require C J_*=-J_* C. Raising C to its
odd half-period15 gives C^15 J_*=-J_* C^15. Since C^15=-I this says
-J_*=J_*, impossible for a complex structure, even without integrality.

This proof uses exact finite arithmetic but proves a universal statement,
not a finite search through selected J candidates. It is consistent with
the known Coxeter centralizer theorem: an irreducible Coxeter element has
cyclic centralizer generated by itself, here of order30, hence without an
order-four element. See Hollenbach and Wegener, The centralizer of a
Coxeter element (2019/2020), https://arxiv.org/abs/1912.01529 . The elementary
mod31 certificate avoids depending on that classification for this result.

The obstruction is to simultaneous lattice preservation, fixed complex
linearity and this C action. It is NOT a contradiction in the original
noncommuting clocks, a no-go for E8, or a proof that complex quantum theory
cannot describe the model. For example the240-dimensional source-label
permutation already implements C on a different complex Hilbert space.

5. Exact positive replacement: a transported-frame family

Set

  J_r=C_G^r J C_G^-r.

The exact census gives fifteen distinct frames, r=0,...,14. Among powers
1,...,30, C_G^k commutes with J only for k=15,30; no power anticommutes with
J. The minimal C-closed orbit of this marked frame therefore has length15.
This is the C orbit only; no classification of the entire C/J/c orbit is
claimed.

The clock is complex-linear BETWEEN neighboring fibers:

  C_G J_r=J_(r+1) C_G,
  C_G Pi_alpha^(J_r) C_G^-1=Pi_(C_G alpha)^(J_(r+1)).

Both identities are checked exactly on all240 roots and all15 frames.
Each frame has60 ray projectors. The entire reflection alphabet

  r_alpha^(J_r)=I-2Pi_alpha^(J_r)

is the C_G^r conjugate of the original alphabet and permutes the original
root set. Thus the finite local rule transports consistently, rather than
having to be fitted independently in every frame.

After15 steps the frame returns and the real vector map is -I; after30
steps the vector map is I. This sign is a fiber monodromy. Whether it is
detectable in a composite observable depends on that observable and its
phase conventions. It is not identified here with a fermion sign, spin,
chirality, a physical time period, or an extra spatial dimension.

6. Connection to the full Hamiltonian family

For each marked frame one may WRITE the same existing source/matter
Hamiltonian prescription with its transported projectors and reflections.
Using source-label permutation R_(C_G) and the complex-linear matter map
between neighboring fibers transports H[J_r] to H[J_(r+1)]. The relative
source distance V is unchanged because C_G is orthogonal. The conditional
event H_E and primitive reflection average L transform by the projector
identity and reindexing of the sixty reflections. J_cpl,kappa,mu are held
fixed in this comparison.

This is covariance of a family of already specified rules. It is not a new
term coupling the fibers, not a ground-state selection, and not a proof
that the old fixed-frame H is itself invariant under C. A direct sum of
fifteen fibers with a chosen hopping would introduce a new Hilbert space
and new energy choices; no such replacement is made here.

The corpus treats J as a chosen root-preserving compiler/source structure
and quarter-clock marking, not as an already derived gauge redundancy.
The physical identification with the raw seam deck remains conditional
through SEAM.EQUIV.01/QGEO.SYM.01. Therefore the remaining physical question
is which same-source operator carries this transport and its currents and
state, or whether the frames are only equivalent descriptions. The algebra
alone does not choose among those interpretations.
